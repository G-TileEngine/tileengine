## How the APK reaches the phones (EA ruling 2; CoS runs it, not the builder)
- After 11b merges, CoS (or EA) builds the CEO's APK **on the box** from merged main: `sh tools/apk/debug-apk.sh [<game.zip>]`. Always the same box, so every APK carries the same debug key and a new one installs over the old one (an APK signed on another machine needs the old app uninstalled first).
- The file goes to a **private Google Drive folder shared only with the CEO** (not public, not a release, not a branch: a binary never goes into git history). Sharing it with him is a message CoS sends only on the CEO's SEND.
- On the phone (Samsung Galaxy S21 Ultra, Red Magic 9 Pro; both far above minSdk 26): open the file from Drive, allow "Install unknown apps" for Drive (or Files) once, and confirm Play Protect's "unknown app" prompt. To play his own game, the CEO taps Build game in the maker (after an approved republish), shares the zip to CoS, and gets back an APK of it.
- No gh-pages publish is part of 11b. Any republish needs the CEO's own typed OK in QA's chat, naming the commit; CoS verifies it there.

## Goal
In plain words:
- **One command, one APK.** `sh tools/apk/debug-apk.sh [<game.zip>]` builds `tools/apk/artifacts/TileEngine-<12 hex>-debug.apk` and prints its sha256; with no zip it packs the demo as an exported game.
- **Only safe input.** The zip must be a **release** 11a export with its project module: a dev export (debug hooks), a zip with no `project/files.js`, a path that leaves `www` or a non-empty `www` is refused before Gradle runs.
- **The phone settings stick.** minSdk 26 and portrait really land on Capacitor 6 files, a file with nothing to patch stops the build, and the INTERNET permission is removed from the manifest.
- **Reproducible tools.** `setup-sdk.sh` fetches Temurin 17.0.21.1+2 and cmdline-tools 11076708 by fixed URL and checks each by sha256.

**Not in 11b:** release signing or a keystore; store upload; app icon, name or splash per game (UX, after 11b: "Game name" and "Icon" in project settings); a per-game app id (store/release step, CoS ruling); device save; a device test run (only the CEO's phones are real devices).
