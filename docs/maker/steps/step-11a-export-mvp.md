## Rules
1. **Zip (`tools/export/zip.ts`, new, pure).** `crc32`, `zipStore(entries)` (stored, method 0, UTF-8 names; each header is its signature plus a list of `[offset, bits, value]` fields) and `unzipStore(zip)` (method 0 only; throws on another method or a bad CRC). No dependency; runs in the browser and in Node. This is the "zipped form" of format L283.
2. **Game zip (`tools/export/game.ts`, new, pure).** `KEEP_OUT = ["notes/", "sprite-recipes/"]`; `shipped(path)` is true only for a `.json` path with **no path segment named `.deleted`** (anywhere, DSK E5(a)) and not under `KEEP_OUT` (so no `.tmp` or other non-JSON text). `filesModule(text)`: `export default {\n"<path>": <saved text>, …\n};` for every shipped path, sorted; **each document's text goes in exactly as saved** (DSK E5(b), E7: no `safe()`, no U+2028/9 escaping; ES2019 allows both raw in strings). It never parses. `markPage(html)`: `<canvas id="board">` becomes `<canvas id="board" data-game="project/files.js">` (throws when absent). `gameZip(play, text, assets)`: the play files except `build.json`, its `index.html` through `markPage`, `project/files.js`, `project/assets/<name>` (none under `.deleted/`); sorted; then a `build.json` with keys `commit, node, entry, files` only (DSK E6 Q3: no new fields), so `ours()` accepts it.
3. **Play boot (`tools/play-stage/game.ts`, new; `page.ts`).** `game.ts` holds `PROJECT = "project/"` and `FILES = "project/files.js"`. `page.ts`: when the board has `data-game`, `import()` that module (resolved against `document.baseURI`) and run `openProject(files)`; links go through `arriveIn(files, link.from, link.to, party)`; pictures read `./project/<file>`. With no `data-game` it opens the demo exactly as today, with **no extra request**. An import failure shows its message (no demo fallback). No `JSON.parse` in `tools/play-stage` (Read first 3). The game reads exactly as Test does: `openProject`'s `readProject` reads up v4/v5 in memory and refuses a doc newer than the engine (typed `needsMigration`/`formatNewer`), with no new code (DSK E7).
4. **Build game (`tools/maker/export.ts`, new).** `buildGame(store, id, get)`: `readTree` → `parseProject` → `readProject` + `assetRows` → `testGate` → `openProject` → `emptyBoard`, each refusal returned as `{ ok: false, lines }` with Test's lines; then the `assets/` bytes by `list` + `readBlob` (skipping a `.deleted` folder; **a listed name whose `readBlob` is null throws `Can't build: assets/<name>`**); the play tree's `build.json` read through **`parseProject`** (the maker's one parser) and **checked by shape** (`commit` and `node` strings, `files` an object of strings; else throws `Can't build: build.json`), each listed file through `get`; then `gameZip`. `playBase(url)`: `…/maker/<stamp>/…` → `…/play-stage/<stamp>/` (first `/maker/`), and **throws when the URL has no `/maker/`**. No refusal on `migrated` rows (DSK E7): old docs ship verbatim and play as in Test.
5. **Button and download (`tools/maker/build-sheet.ts`, new; `home.ts`; `app.css`; UX to EA, 2026-11-26).** `BuildView` is `idle | busy` (11a2 widens it). `buildButton`: idle `<button class="btn ghost stage-row" data-act="build">Build game</button>` (full width, 48 px, secondary), busy the same button `disabled aria-busy="true"` reading `<span class="spin">` + `Building…`. `home.ts`: the button after the stages (`tail:`), the `build` act; `buildNow`: `if (state.dirty) await saveCurrent();` then **`if (state.dirty) return;`** (QA must-fix: a failed save stops Build, as Test does); busy, paint; `buildGame`; a refusal sets `state.problems` (Test's sheet); else `download(file)`, a `File` named `<projectId>-game.zip` through an object URL; **a throw sets `state.banner` to the plain reason** (the maker's existing status line, as `say()` and `fail()` use it: interim until 11a2's sheets, kept minimal); then idle, paint.
