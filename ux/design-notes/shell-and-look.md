# Shell and look — standing rules

- Locked shell (CEO 2026-11-09): thin top bar, bottom rail of 6 tools, contextual sheet at most 40% height, grid 75%+ when closed. r72 keeps the bottom rail on tablet/PC from 768px.
- Every feature is a few buttons and sliders, all code hidden. Basic adds zero taps; depth goes under Advanced. Don't dumb it down.
- 48px+ touch targets, AA contrast, light/dark/follow device (dark mode called "the most important feature").
- Reference look is r62 (calm). Avoid the "Isberg Labs" feel: code wall, tiny menus, dense palette, "need a YouTube guide".
- TileEngine is a game maker first, plus a standalone 2D asset tool. No 3D.
