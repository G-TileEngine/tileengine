## Where things go
- **Repo:** https://github.com/G-TileEngine/tileengine (visibility is the CEO's call). `README.md` on `main` is owned by CoS; steps never edit it. Nobody pushes to `main`; it changes only by merged PR.
- **Publishing (CoS):** push one kit commit to `main` with `BUILD_GUIDE.md` (root), `docs/STATES.md`, `src/types/core-types.ts` (or attach them to step 00). That commit is step 00's base. The Architect then writes each step's base SHA into the step file before it is sent.
- **Per step:** Grok Build works on branch `step/<step-id>-r<N>` from the base (`main`'s SHA after the previous accepted step), commits the hand-back in-repo at `handback/<step-id>/r<N>/` as the last commit, and delivers a verified git bundle plus HAND-BACK.md to the CEO's Drive; Chief Of Staff pushes the branch and opens the PR to `main` (CN-003). Architect review → QA (G1–G10 on a clean clone of the branch) → RaiKynn accepts via CoS → the Architect merges. Tagging is not used; merge commits on `main` are the record.
- **Change Notices:** `change-notices/CN-<NNN>-<slug>.md` here, attached to the step that carries them. Issued: `CN-001-sim-time-ms.md` (sim time is integer ms; carried by step 02), `CN-002-no-card-types-camelcase.md` (no-card-types also catches camelCase Card/Deck names; carried by step 01), `CN-003-delivery-bundle.md` (delivery is a git bundle to the CEO's Drive; Chief Of Staff opens the PR; carried by step 01), `CN-004-core-types-audio-ui-keys.md` (core-types adds `audio: 1`, `CORE_EVENT_KEYS` and `UiEventMap`; carried by step 02), `CN-005-project-reads-notice.md` (`src/project` may import the type-only `Notice`; carried by step 08), `CN-006-input-layer-sim-script.md` (`src/runtime/input` layer, the `sim` npm script and `scripts/sim.ts`, BUILD_GUIDE §3; carried by step 09c), `CN-007-fx-layer.md` (`src/fx` layer: one depcruise line and two BUILD_GUIDE §3 lines; carried by step 10), `CN-008-paint-layer.md` (`src/paint` layer: two depcruise lines, one `check:law` gate and two BUILD_GUIDE §3 lines; new `.dependency-cruiser.cjs` pin `45a3dbaa…`; carried by SE-01).
